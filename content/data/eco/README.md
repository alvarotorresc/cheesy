# ECO dataset

Names, ECO codes and move orders of chess openings, from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings), dedicated to the public
domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The files `a.tsv` to `e.tsv` are copied unchanged. They are only used by `pnpm content:verify` to
check the names and codes of the openings; the app does not ship them.
